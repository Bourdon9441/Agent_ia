# Agent_ia

Centre de contrôle pour assistants IA : un « Patron » qui distribue les tâches et jusqu'à 10 agents qui les exécutent, en mode autonome.

## Utilisation

Ouvrir `index.html` dans un navigateur (aucune installation nécessaire).

- **Embaucher des agents** : 1 à 10, chacun avec un nom et une spécialité.
- **Le Patron** : recevez un objectif, il le découpe en tâches et les distribue aux agents libres.
- **Mode autonome** : le Patron relance des cycles de travail en continu à partir de la mission principale, même en votre absence (laisser l'onglet ouvert).
- **IA réelle (optionnel)** : dans ⚙️ Connexion IA réelle, coller une clé API Mistral. Sans clé, tout fonctionne en mode simulation.

Les données sont sauvegardées dans le navigateur (localStorage).
